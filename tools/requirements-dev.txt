# Local development pins for the maintained Python tooling.
#
# These versions are the ones hosted CI installs. Local results are only
# comparable to CI when they match exactly, so tools/dev_check.sh verifies the
# installed versions against this file and refuses to report a clean run on a
# mismatch.
#
# Sources of truth this file mirrors:
#   ruff, mypy       -> .github/workflows/static-checks.yml (RUFF_VERSION, MYPY_VERSION)
#                       and tools/requirements-quality-ci.txt
#   coverage, PyYAML -> tools/requirements-coverage-ci.txt
#   PyYAML            -> tools/requirements-portfolio-ci.txt
#
# Hosted Ubuntu/Python 3.10 jobs install from the platform-specific hash locks
# above using --only-binary=:all: --require-hashes. This cross-platform local
# file stays version-pinned but intentionally does not duplicate every wheel
# hash; tools/dev_check.sh proves its versions still mirror the CI locks.
#
# actionlint is a Go binary, not a Python package. static-checks.yml installs
# 1.7.12 and accepts it only after matching a pinned SHA-256. dev_check.sh uses
# actionlint when it is already on PATH and reports workflow validation as
# SKIPPED when it is not, rather than implying that step passed.
#
# To remove that skip locally, install the same pinned, SHA-verified binary that
# static-checks.yml uses and put it on PATH:
#
#   v=1.7.12
#   sha=8aca8db96f1b94770f1b0d72b6dddcb1ebb8123cb3712530b08cc387b349a3d8
#   curl -fsSL -o actionlint.tar.gz \
#     "https://github.com/rhysd/actionlint/releases/download/v${v}/actionlint_${v}_linux_amd64.tar.gz"
#   printf '%s  %s\n' "$sha" actionlint.tar.gz | sha256sum -c -
#   tar --no-same-owner -xzf actionlint.tar.gz actionlint
#
# Keep the version and digest above in step with static-checks.yml, which stays
# the source of truth for both.
#
# Install:  python3 -m pip install -r tools/requirements-dev.txt
