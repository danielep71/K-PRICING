# Only class "supported" is API: the 22 KPR_Dates_* functions of docs/PUBLIC_API.txt
# and docs/DATE_LAYER_CONTRACT.md section 2, with their vectorization
# (array-capable or scalar-only). Every other class is unsupported infrastructure:
# technically public because VBA, Application.Run, MacroOptions, RibbonX,
# CommandBars, the tests or the demo builder need it, and free to change
# without notice. Its vectorization is "-".
#
#   supported     the worksheet and VBA date API (src/modules/KPR_DATES_DAYS.bas)
#   internal      src/core primitives behind Option Private Module
#   registration  the MacroOptions register/clear lifecycle and its manifest (#42)
#   ui            menu actions, the KPR Dates toolbar and the Ribbon callbacks (#47, #48)
#   test          the regression runner, generated fixtures and the Excel oracle
#   development   the development loader and the one-click Excel check
#   demo          the demo builder, the Date Primitives demo and the direct-VBA example
#
# tools/check_kpr_contract.py (rule kpr-api-inventory) fails when a public member
# is missing here or listed but gone, when a class does not fit its component's
# role, when the supported set or a vectorization differs from the contract, when
# a KPR_Dates_* procedure appears outside the facade, or when a _Spill name or a
# reserved name is declared.
#
